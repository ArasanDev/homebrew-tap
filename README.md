# ArasanDev Homebrew tap

```sh
brew trust arasandev/tap          # Homebrew 7+ trusts third-party taps explicitly
brew install --cask arasandev/tap/yt
```

## yt

YouTube transcripts, transcript search, and channel monitoring for agents and
humans. One static Go binary; CLI + MCP server.

- Source: <https://github.com/ArasanDev/yt>
- Releases: <https://github.com/ArasanDev/yt/releases>
- Install without Homebrew:
  `curl -fsSL https://raw.githubusercontent.com/ArasanDev/yt/main/install.sh | sh`
